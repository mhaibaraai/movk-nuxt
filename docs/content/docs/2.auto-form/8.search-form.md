## 简介

`MSearchForm` 是一个 Schema 驱动的搜索表单组件，内置网格布局、搜索 / 重置按钮和折叠行为。当搜索项较多时，超出可见行数的字段会自动折叠，用户可点击展开 / 收起按钮查看全部搜索项。

::callout{color="neutral" to="/docs/auto-form/quickstart"}
复用 AutoForm 基础设施（schema 内省、控件映射、字段渲染器），通过 Zod schema 定义搜索字段。
::

### `v-model` 绑定

`v-model` 双向绑定表单数据，传入的初始值会被记录为重置基准：点「重置」恢复到该初始值而非清空。

```vue
<script setup lang="ts">
const { afz } = useAutoForm()
const schema = afz.object({ name: afz.string().optional() })
const state = ref({ name: 'Alice' })
</script>

<template>
  <MSearchForm v-model="state" :schema="schema" />
</template>
```

### `syncQuery` 查询参数同步

`syncQuery` 作用：设为 `true` 后挂载时从 URL query 还原字段，在搜索、重置与清空时写回；默认 `false`。仅替换 schema 顶层字段对应的 query，保留路由中的其他参数。默认使用 `router.replace`，对象形态的 `replace: false` 改用 `router.push`。

默认解析器按 schema 还原数字与布尔值，数组保留为多值，对象使用 JSON。对象形态的 `parse(query)` / `serialize(state)` 可自定义协议。query 只在挂载时读取，路由后续变化不会自动覆盖正在编辑的表单；示例通过重新挂载演示回读。

### `transformPayload` 提交清洗

`transformPayload` 作用：默认 `true` 时对提交数据的顶层字符串去首尾空白并剔除空字符串、`null` 与 `undefined`；`false` 原样提交；函数形态接收数据并返回自定义载荷。只影响 `@submit` 的 `event.data`，不会改写 `v-model`。URL 写入会独立执行默认清洗，即使提交使用 `false`。

下例的 `off` / `default` / `custom` 对应关闭、默认同步与自定义 query 协议；`clean` / `raw` / `custom` 对应默认清洗、原样提交与关键词转大写。自定义同步将关键词写为 `search:关键词` 并使用 `router.push`。先填入空白样本，再切换模式并搜索，对照表单值、提交值与 URL。

::component-example
---
name: ComponentsSearchFormQueryExample
options:
  - name: query-mode
    label: syncQuery
    items: ['off', 'default', 'custom']
    default: off
  - name: payload-mode
    label: transformPayload
    items: ['clean', 'raw', 'custom']
    default: clean
---
::

| `toggle()`{lang="ts-type"} | `void`{lang="ts-type"} <br> <div class="text-default mt-1"><p>切换展开 / 收起，并 emit `expand` 与 `update:expanded`</p> |
