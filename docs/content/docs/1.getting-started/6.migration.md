## 概述

v2 重新聚焦 Schema 驱动的中后台能力（AutoForm、SearchForm、DataTable、API），移除了与 Nuxt UI 重叠或复用价值较低的组件。下文列出全部破坏性变更与替代方案。

## 移除的组件

| 组件 | 替代方案 |
| --- | --- |
| `MWithClear` | `UInput` 组合写法，见 [Nuxt UI Input 示例](https://ui.nuxt.com/docs/components/input#with-clear-button) |
| `MWithCopy` | `UInput` 组合写法，见 [Nuxt UI Input 示例](https://ui.nuxt.com/docs/components/input#with-copy-button) |
| `MWithPasswordToggle` | `UInput` 组合写法，见 [Nuxt UI Input 示例](https://ui.nuxt.com/docs/components/input#with-password-toggle) |
| `MWithCharacterLimit` | `UInput` 组合写法，见 [Nuxt UI Input 示例](https://ui.nuxt.com/docs/components/input#with-character-limit) |
| `MWithFloatingLabel` | `UInput` 组合写法，见 [Nuxt UI Input 示例](https://ui.nuxt.com/docs/components/input#with-floating-label) |
| `MAsPhoneNumberInput` | `UInput` 组合写法，见 [Nuxt UI Input 示例](https://ui.nuxt.com/docs/components/input#as-a-phone-number-input) |
| `MPillGroup` | `URadioGroup` / `UCheckboxGroup` 的 `variant="card"`，或 `UTabs` |
| `MColorChooser` | `UColorPicker` 放入 `UPopover` |
| `MSlideVerify` | 无内置替代，可自行实现或接入第三方人机验证服务 |
| `MPopconfirm` | `UPopover` 内放置确认按钮，或使用命令式的 [`useMessageBox`](/docs/components/message-box#usemessagebox) |

同时移除了 `maska` 与 `colortranslator` 依赖，以及上述组件对应的 Props / Emits / Slots 类型导出（如 `WithClearProps`、`PillGroupProps`、`ColorChooserProps`）。

## 移除的 AutoForm 控件类型

以下 `type` 值不再内置，继续使用会渲染 `[AutoForm] No control mapped` 提示：

- `withClear`、`withPasswordToggle`、`withCopy`、`withCharacterLimit`、`withFloatingLabel`、`asPhoneNumberInput`
- `colorChooser`、`slideVerify`、`pillGroup`

简单场景直接用默认 `UInput` 的 `controlProps`：

```ts
const schema = afz.object({
  // 之前：afz.string({ type: 'withPasswordToggle' })
  password: afz.string({ controlProps: { type: 'password' } }),
  // 之前：afz.enum([...], { type: 'pillGroup' })
  category: afz.enum(['全部', '前端', '后端'], {
    type: 'radioGroup',
    controlProps: { orientation: 'horizontal' }
  })
})
```

需要复用的增强输入框，在项目内封装组件后通过 `defineControl` 注册为控件类型，沿用原有的 `type` 名称即可无缝迁移：

```ts
import PasswordInput from '~/components/PasswordInput.vue'

const { afz, controls } = useAutoForm({
  withPasswordToggle: defineControl({
    component: PasswordInput,
    controlProps: { class: 'w-full' }
  })
})
```

详见 [控件与自定义控件](/docs/auto-form/controls#自定义控件)。

## 适配 Nuxt UI v5

v2 以 `@nuxt/ui` v5 为基线，以下变更随之而来。

### 模块选项

| v1 | v2 |
| --- | --- |
| `movk.theme.colors` | 移除，颜色改在 CSS 中配置，见下文 |
| `movk.theme.defaultVariants` | 移除，改用 `app.config.ts` 的 `ui.defaultVariants` |
| `movk.theme.prefix` | 缺省沿用 `ui.tailwindPrefix`（原 `ui.theme.prefix`） |
| `ui.experimental.componentDetection` | `ui.componentDetection`，v5 缺省开启 |

### 颜色

模块不再注入 `blue` / `slate` 默认色，跟随 Nuxt UI v5 的默认值。需要自定义时在项目 CSS 中配置：

```css
@import "tailwindcss";
@import "@movk/nuxt";

@plugin "@nuxt/ui/colors" {
  primary: blue;
  neutral: slate;
}
```

`useTheme` 的 `primary` / `neutral` 在未选择时为 `undefined`；切换后改为在 `<html>` 上写入 `--ui-color-{primary,neutral}-*` 变量，`exportCSS()` 输出上面的 `@plugin` 配置，`exportConfig()` 不再包含颜色。

### 组件主题覆盖

覆盖由 `app.config.movk.<组件>` 移至 `app.config.ui.movk<组件>`，并支持 `<UTheme>` 层级覆盖：

```ts [app.config.ts]
export default defineAppConfig({
  ui: {
    movkTree: { slots: { container: 'gap-4' } },
    movkDataTable: { slots: { toolbar: 'pb-4' } }
  }
})
```

| v1 | v2 |
| --- | --- |
| `movk.autoForm` | `ui.movkAutoForm` |
| `movk.searchForm` | `ui.movkSearchForm` |
| `movk.dataTable` | `ui.movkDataTable` |
| `movk.dataTablePagination` | `ui.movkDataTablePagination` |
| `movk.datePicker` | `ui.movkDatePicker` |
| `movk.messageBox` | `ui.movkMessageBox` |
| `movk.themePicker` | `ui.movkThemePicker` |
| `movk.tree` | `ui.movkTree` |

`app.config.movk.tv`、`app.config.movk.prefix` 移除，合并配置改用 `ui.tv`。`app.config.movk` 只保留 `radius`、`icons`、`blackAsPrimary`、`picker` 等主题选项。

### DataTable 与 TanStack Table v9

`MDataTable` 需要 `@tanstack/vue-table ^9.3.1`。升级依赖后，将 `sortingOptions`、`columnSizingOptions`、`columnPinningOptions`、`rowSelectionOptions`、`expandedOptions`、`paginationOptions` 等选项合并到 `options`：

```vue
<!-- v1 -->
<MDataTable
  :sorting-options="{ manualSorting: true }"
  :pagination-options="{ manualPagination: true, rowCount: total }"
/>

<!-- v2 -->
<MDataTable
  :options="{ manualSorting: true, manualPagination: true, rowCount: total }"
/>
```

`options` 中显式提供的配置优先于由列配置派生的值。客户端分页所需的 feature 和行模型由组件自动注册；额外的 TanStack 功能通过 `features` 传入，并在脚本中一次性声明。

| 原写法 | v2 写法 |
| --- | --- |
| `fixed: 'left'` / `fixed: 'right'` | `fixed: 'start'` / `fixed: 'end'` |
| `columnPinning: { left: [...], right: [...] }` | `columnPinning: { start: [...], end: [...] }` |
| `Table<T>` | `Table<TableFeatures, T>` |
| `Row<T>` | Nuxt UI 的 `TableRow<T>` |
| `Column<T>` / `Cell<T, TValue>` | `Column<TableFeatures, T>` / `Cell<TableFeatures, T, TValue>` |
| `tableApi.getState().pagination` | `tableApi.atoms.pagination.get()` |
| `columnSizingInfo` | `columnResizing` |

`start` / `end` 跟随文字方向，在 RTL 下会交换物理左右侧，不保留旧值兼容映射。若业务自行保存了固定列状态，也须转换键名。`TableFeatures`、`TableRow` 从 `@nuxt/ui` 导入，`Table`、`Column`、`Cell` 从 `@tanstack/vue-table` 导入；回调优先从 `DataTableDataColumn<T>['cell']` 等公开类型派生。

选中状态只保存值为 `true` 的条目，取消选中会移除对应键；不要再以键是否存在且值为 `false` 判断取消状态。设置 `size` 的列按指定宽度渲染，需要内容自适应时仅设置 `minSize` / `maxSize`，详见 [列宽规则](/docs/data-table/columns)。

多选复选框默认支持 Shift 区间选择，区间按当前排序后的行顺序解析；传入 `:options="{ enableRowRangeSelection: false }"` 可关闭此行为。

### Tree 节点标识

`MTree` 新增 `valueKey`，默认值为 `'value'`。节点 key 按 `getKey` 的非空返回值、`valueKey` 指向的字符串或数字、`labelKey` 的顺序解析；数字转换为字符串。`valueKey` 和 `labelKey` 都支持点路径。

已有节点同时包含 `value` 和 `label` 时，默认 key 从 label 改为 value。同步调整 `selectedKeys`、`expanded` 等受控 key，或传入 `value-key="label"` 保留按 label 取键的行为；已有自定义 `getKey` 仍优先。详见 [Tree](/docs/components/tree)。

### 输入控件样式

Nuxt UI v5 将输入控件的外框从 `base` 移至 `root`。通过 AutoForm `controlProps.ui` 或控件主题自定义边框、背景、圆角时，将相应类移至 `root`；焦点外框使用 `has-[>:focus]:`。不要继续通过 `ps-*` / `pe-*` 为 leading / trailing 图标预留位置。

`USelectMenu` 的 `searchInput` 改为 `filter`。自定义控件不再传入已移除的 `fixed` prop，主题中的图标、间距与字号应沿用 v5 的 control scale 变量。背景 token `bg-elevated` / `bg-accented` 分别改为 `bg-soft` / `bg-strong`。

### 其他

- `useDateFormatter` 未传 `locale` 时跟随 `<UApp :locale>`，组件外调用回退为 `'en'`（原为 `'zh-CN'`）。
- `MDatePicker` 清除范围值后得到 `undefined`（原为 `{ start: undefined, end: undefined }`）。
- 移除 `tailwind-variants` 依赖。
