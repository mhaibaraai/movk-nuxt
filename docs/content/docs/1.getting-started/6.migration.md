## 概述

v2 重新聚焦 Schema 驱动的中后台能力（AutoForm、SearchForm、DataTable、API），移除了与 Nuxt UI 重叠或复用价值较低的组件。下文列出全部破坏性变更与替代方案。

## 移除的组件

| 组件 | 替代方案 |
| --- | --- |
| `MWithClear` | `UInput` 组合写法，见 [Nuxt UI Input 示例](https://ui.nuxt.com/docs/components/input#with-clear-button) |
| `MWithCopy` | `UInput` 组合写法，见 [Nuxt UI Input 示例](https://ui.nuxt.com/docs/components/input#with-copy-button) |
| `MWithPasswordToggle` | `UInput` 组合写法，见 [Nuxt UI Input 示例](https://ui.nuxt.com/docs/components/input#with-password-toggle) |
| `MWithCharacterLimit` | `UInput` 组合写法，见 [Nuxt UI Input 示例](https://ui.nuxt.com/docs/components/input#with-character-limit) |
| `MWithFloatingLabel` | `UInput` 组合写法，见 [Nuxt UI Input 示例](https://ui.nuxt.com/docs/components/input#with-floating-label) |
| `MAsPhoneNumberInput` | `UInput` 组合写法，见 [Nuxt UI Input 示例](https://ui.nuxt.com/docs/components/input#as-a-phone-number-input) |
| `MPillGroup` | `URadioGroup` / `UCheckboxGroup` 的 `variant="card"`，或 `UTabs` |
| `MColorChooser` | `UColorPicker` 放入 `UPopover` |
| `MSlideVerify` | 无内置替代，可自行实现或接入第三方人机验证服务 |
| `MPopconfirm` | `UPopover` 内放置确认按钮，或使用命令式的 [`useMessageBox`](/docs/components/message-box#usemessagebox) |

同时移除了 `maska` 与 `colortranslator` 依赖，以及上述组件对应的 Props / Emits / Slots 类型导出（如 `WithClearProps`、`PillGroupProps`、`ColorChooserProps`）。

## 移除的 AutoForm 控件类型

以下 `type` 值不再内置，继续使用会渲染「控件未映射」提示：

- `withClear`、`withPasswordToggle`、`withCopy`、`withCharacterLimit`、`withFloatingLabel`、`asPhoneNumberInput`
- `colorChooser`、`slideVerify`、`pillGroup`

简单场景直接用默认 `UInput` 的 `controlProps`：

```ts
const schema = afz.object({
  // 之前：afz.string({ type: 'withPasswordToggle' })
  password: afz.string({ controlProps: { type: 'password' } }),
  // 之前：afz.enum([...], { type: 'pillGroup' })
  category: afz.enum(['全部', '前端', '后端'], {
    type: 'radioGroup',
    controlProps: { orientation: 'horizontal' }
  })
})
```

需要复用的增强输入框，在项目内封装组件后通过 `defineControl` 注册为控件类型，沿用原有的 `type` 名称即可无缝迁移：

```ts
import PasswordInput from '~/components/PasswordInput.vue'

const { afz, controls } = useAutoForm({
  withPasswordToggle: defineControl({
    component: PasswordInput,
    controlProps: { class: 'w-full' }
  })
})
```

详见 [控件与自定义控件](/docs/auto-form/controls#自定义控件)。

## 文档路径调整

文档按能力域重新组织，旧链接会自动重定向：

- `/docs/composables/*` 拆入对应能力域：`useAutoForm` → 表单、`useTheme` → 主题、`useMessageBox` / `useDateFormatter` → 对应组件页、上传下载与流式请求 → API
- AutoForm 的字段类型页合并为 [字段类型](/docs/auto-form/field-types)，`SearchForm` 移入表单章节
- AI 集成三页合并为 [AI 集成](/docs/getting-started/ai)
