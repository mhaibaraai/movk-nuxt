## MCP Server

### 什么是 MCP？

MCP (Model Context Protocol) 是一个标准化协议，使 AI 助手能够访问外部数据源和工具。Movk Nuxt 提供 MCP 服务器，让 AI 工具能够直接访问组件信息、API 文档和使用示例。

### 可用资源

MCP 服务器提供以下资源供 AI 发现和浏览：

| 资源 URI | 描述 |
|---------|------|
| `resource://docs/components`{lang="ts-type"} | 组件完整列表，包含元数据和分类信息 |
| `resource://docs/composables`{lang="ts-type"} | 组合式函数完整列表，包含元数据和分类信息 |
| `resource://movk-nuxt/auto-form`{lang="ts-type"} | AutoForm 系统完整文档，包含配置、API、字段定义和自定义选项 |
| `resource://movk-nuxt/data-table`{lang="ts-type"} | DataTable 系统完整文档，包含列配置、树形、分页和样式定制 |
| `resource://movk-nuxt/api`{lang="ts-type"} | API 系统完整文档，包含插件配置、Hooks、Composables 和进度上传/下载 |
| `resource://docs/documentation-pages`{lang="ts-type"} | 所有可用文档页面的完整列表 |
| `resource://docs/examples`{lang="ts-type"} | 所有可用示例代码和演示的完整列表 |

在 Claude Code 等工具中使用 `@` 访问这些资源。

### 可用工具

#### 列表查询

| 工具名称 | 描述 |
|---------|------|
| `list-components`{lang="ts-type"} | 列出所有 Movk Nuxt 组件及其分类和基本信息 |
| `list-examples`{lang="ts-type"} | 列出文档站所有可用示例 |
| `list-api`{lang="ts-type"} | 列出 API 系统文档，覆盖插件、Hooks 和 Composables |
| `list-data-table`{lang="ts-type"} | 列出 DataTable 系统全部文档 |

#### 详情获取

| 工具名称 | 描述 |
|---------|------|
| `get-documentation-page`{lang="ts-type"} | 获取特定文档页面的完整内容。支持 `headings` 参数（h2 标题数组，如 `["Usage", "API"]`）以减少响应大小 |
| `get-example`{lang="ts-type"} | 获取示例的实现代码，需提供 `exampleName` 参数（PascalCase） |
| `get-component`{lang="ts-type"} | 获取指定组件的完整 API 文档与用法说明 |
| `get-component-metadata`{lang="ts-type"} | 获取指定组件的元数据（props、slots、emits 等结构化信息） |

#### 搜索过滤

| 工具名称 | 描述 |
|---------|------|
| `search-documentation`{lang="ts-type"} | 按标题、路径、描述或文档章节搜索 |
| `search-composables`{lang="ts-type"} | 按关键词搜索 Composables |
| `search-icons`{lang="ts-type"} | 搜索可用图标 |
| `search-components-by-category`{lang="ts-type"} | 按分类或关键词搜索组件 |
| `search-auto-form-by-category`{lang="ts-type"} | 按关键词搜索 AutoForm 文档 |
| `search-data-table-by-category`{lang="ts-type"} | 按分类或关键词搜索 DataTable 文档 |
| `search-api-by-category`{lang="ts-type"} | 按分类或关键词搜索 API 系统文档 |

::tip
对于大型文档页面，AI 可以使用 `get-documentation-page` 的 `headings` 参数仅获取相关部分（如「Usage」或「API」），减少响应大小并提高性能。
::

### 可用提示

MCP 服务器为常见工作流提供引导式提示：

| 提示名称 | 描述 |
|---------|------|
| `find-component-for-usecase`{lang="ts-type"} | 根据使用场景推荐最适合的组件 |
| `find-autoform-solution`{lang="ts-type"} | 根据表单需求推荐字段类型和配置方案 |
| `implement-component-with-props`{lang="ts-type"} | 按指定 props 给出组件落地实现指引 |

在 Claude Code 等工具中使用 `/` 访问这些提示。

### 配置

Movk Nuxt MCP 服务器使用 HTTP 传输，可在不同 AI 助手中配置。

#### ChatGPT

::note
自定义连接器使用 MCP 功能需要 ChatGPT Pro 或 Plus 账户，仅在 Web 端可用。
::

将 Movk Nuxt 配置为 ChatGPT 连接器：

1. 启用开发者模式：进入「Settings」>「Connectors」>「Advanced settings」>「Developer mode」
2. 打开 ChatGPT 设置
3. 在 Connectors 标签页中创建新连接器：
   - 名称：`Movk Nuxt`
   - MCP server URL：`https://nuxt.mhaibaraai.cn/mcp`
   - Authentication：`None`
4. 点击 Create

后续对话可在编辑器「Developer mode」工具列表中调用该连接器。

#### Claude Code

::note
确保已安装 Claude Code。参阅 [Anthropic 文档](https://docs.anthropic.com/en/docs/claude-code/quickstart) 获取安装说明。
::

通过 CLI 命令添加服务器：

```bash
claude mcp add --transport http movk-nuxt https://nuxt.mhaibaraai.cn/mcp
```

#### Claude Desktop

1. 打开 Claude Desktop，进入「Settings」>「Developer」
2. 点击「Edit Config」打开本地 Claude 配置目录
3. 编辑 `claude_desktop_config.json`：

```json [claude_desktop_config.json]
{
  "mcpServers": {
    "movk-nuxt": {
      "command": "npx",
      "args": [
        "mcp-remote",
        "https://nuxt.mhaibaraai.cn/mcp"
      ]
    }
  }
}
```

4. 重启 Claude Desktop，Movk Nuxt MCP 服务器即注册成功

### 使用示例

配置完成后，可按 Movk Nuxt 四大能力域向 AI 助手提问：

**AutoForm（Schema 驱动表单）**
- 「如何用 Zod schema 自动生成表单？」
- 「支持哪些字段类型？如何注册自定义控件？」
- 「如何实现字段条件渲染与跨字段联动？」
- 「我想做一个用户注册表单，应该怎么组织 schema？」

**DataTable（数据表格）**
- 「DataTable 的列定义有哪些字段，如何用函数式 column？」
- 「如何实现树形数据、列固定与列拖拽？」
- 「如何配置分页、加载更多与空状态？」
- 「我要做一个带行右键菜单的可编辑表格，应该用哪些 API？」

**API 系统（fetch 与进度）**
- 「`useApiFetch` 和 `$fetch` 有什么区别？」
- 「如何配置多端点与自动认证？」
- 「如何监控文件上传/下载进度？」
- 「业务状态码与 Toast 提示如何接入？」

**独立组件与 Composables**
- 「有哪些独立 UI 组件可用？」
- 「DatePicker、Tree、MessageBox 接受哪些 props？」
- 「`useDateFormatter`、`useTheme`、`useMessageBox` 怎么用？」
- 「我需要一个可选日期范围的选择器，推荐用哪个组件？」

AI 助手可以通过 MCP 工具查询文档和示例。也可以在支持 MCP 提示的客户端中手动选择引导式提示。

## LLMs.txt

### 什么是 LLMs.txt？

LLMs.txt 是专为大型语言模型（LLM）设计的结构化文档格式。Movk Nuxt 提供 LLMs.txt 文件，其中包含 Nuxt 模块的完整信息，使 AI 工具能够更好地理解和协助 Movk Nuxt 的开发。

这些文件针对 AI 消费进行了优化，包含组件 API、Composables 签名、Schema 定义、使用模式和最佳实践的结构化信息。

### 可用端点

我们提供 LLMs.txt 端点来帮助 AI 工具访问我们的文档：

- `/llms.txt` - 包含所有组件和 Composables 的结构化概览及其文档链接（约 5K tokens）
- `/llms-full.txt` - 提供完整文档，包括实现细节、示例、类型定义和最佳实践（100K+ tokens）

### 选择正确的文件

::note
**大多数用户应该从 /llms.txt 开始** - 它包含所有基本信息，适用于标准 LLM 上下文窗口。仅当您需要完整的实现示例且 AI 工具支持大型上下文（200K+ tokens）时，才使用 `/llms-full.txt`。
::

### 重要使用说明

::warning
**@ 符号必须手动输入** - 使用 Cursor 或 Windsurf 等工具时，必须在聊天界面中手动输入 `@` 符号。复制粘贴会破坏工具识别它作为上下文引用的能力。
::

### AI 工具使用方法

任何支持 LLMs.txt 的 AI 工具都可以使用这些端点来更好地理解 Movk Nuxt。

- "使用 Movk Nuxt 文档 [https://nuxt.mhaibaraai.cn/llms.txt](https://nuxt.mhaibaraai.cn/llms.txt)"
- "遵循 Movk Nuxt 完整指南 [https://nuxt.mhaibaraai.cn/llms-full.txt](https://nuxt.mhaibaraai.cn/llms-full.txt)"

## Agent Skills

`movk-nuxt` 是一个遵循 [Agent Skills 规范](https://agentskills.io/specification) 的使用指南。入口 `SKILL.md` 说明如何选择 Nuxt 或 Vue + Vite 模式，Agent 会按任务读取相关参考文件：

| 任务 | 参考文件涵盖的内容 |
| --- | --- |
| 构建编辑表单或筛选栏 | Zod v4、AutoForm、自定义控件、SearchForm 和 URL 查询同步 |
| 构建数据表格 | 列和行操作、树形数据、分页、滚动加载及 CSV 导出 |
| 接入 Nuxt 项目的后端 | API 端点和认证、`useApiFetch`、传输进度、SSE 和 AI SDK 聊天传输 |
| 选择界面组件 | DatePicker、Tree、MessageBox 和 ThemePicker |
| 使用组合式函数 | 日期格式化、确认弹窗、主题设置和本地化 |

### 安装

在要使用此 skill 的项目目录中运行 [Skills CLI](https://skills.sh)：

```bash
npx skills add https://nuxt.mhaibaraai.cn --skill movk-nuxt
```

也可以直接从 GitHub 安装：

```bash
npx skills add https://github.com/mhaibaraai/movk-nuxt/tree/main/docs/skills/movk-nuxt --skill movk-nuxt
```

默认安装到当前项目。可以追加 `--agent codex` 或 `--agent claude-code` 来指定客户端，也可以追加 `--global` 以便跨项目使用。
