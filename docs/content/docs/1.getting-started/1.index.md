## 什么是 Movk Nuxt

Movk Nuxt 是基于 [Nuxt UI](https://ui.nuxt.com) 的 **Schema 驱动中后台 CRUD 工具包**。它不重复实现 Nuxt UI 已有的基础组件，而是把中后台页面里反复出现的几件事编排起来：

- 用 [Zod v4](https://zod.dev) Schema 描述数据，由 `MAutoForm` 生成表单、`MSearchForm` 生成搜索条件；
- 用声明式列配置驱动 `MDataTable`，承载选择、排序、树形数据与分页；
- 在 Nuxt 中用 `useApiFetch` 统一端点、认证、业务状态码与提示，把数据接到上面的表单和表格。

适合需要大量增删改查页面的管理后台、内部工具与运营系统。如果只需要通用 UI 组件，直接使用 Nuxt UI 即可。

## 能力域

::card-group
  :::card{icon="i-lucide-square-pen" title="表单" to="/docs/auto-form"}
  `MAutoForm` 由 Zod Schema 生成字段、校验与布局，支持自定义控件、条件显示与数组对象；`MSearchForm` 复用同一套 Schema 生成可折叠的搜索栏。
  :::

  :::card{icon="i-lucide-table" title="数据表格" to="/docs/data-table"}
  `MDataTable` 基于 TanStack Table，提供数据列与选择、索引、展开、操作等特殊列，以及排序、列固定、树形数据与分页。
  :::

  :::card{icon="i-lucide-cloud" title="API（仅 Nuxt）" to="/docs/api"}
  `useApiFetch` 系列在 `useFetch` 之上封装多端点、认证注入、业务状态码校验、数据解包与 Toast，并提供带进度的上传下载与流式请求。
  :::

  :::card{icon="i-lucide-box" title="组件" to="/docs/components/date-picker"}
  `MDatePicker`、`MTree`、`MMessageBox` 补足中后台常用交互，`MThemePicker` 与 `useTheme` 负责运行时主题。
  :::
::

## 两种使用方式

| | Nuxt 模式 | Vue + Vite 模式 |
| --- | --- | --- |
| 接入方式 | Nuxt 模块 `@movk/nuxt` | Vite 插件 `@movk/nuxt/vite` + Vue 插件 `@movk/nuxt/vue-plugin` |
| 表单、搜索、表格 | 可用 | 可用 |
| DatePicker、Tree、MessageBox、ThemePicker | 可用 | 可用 |
| `useAutoForm`、`useTheme`、`useDateFormatter`、`useMessageBox`、`useMovkLocale` | 可用 | 可用 |
| API 域（`useApiFetch` 系列、`$api`、上传下载、流式请求、认证与 Toast） | 可用 | 不可用 |

API 域依赖 Nuxt 的服务端运行时与 `runtimeConfig`，因此只在 Nuxt 模式提供。Vue + Vite 项目请自行选择请求方案。

::note{to="/docs/getting-started/vue"}
在纯 Vue + Vite 项目中接入，见 Vue / Vite 集成。
::

## 依赖关系

- **Nuxt UI v5**：所有组件构建在 Nuxt UI 之上，主题、颜色、国际化沿用 Nuxt UI 的机制。
- **Tailwind CSS v4**：样式由项目的 Tailwind 入口统一编译。
- **Zod v4**：表单与搜索的 Schema 来源。
- **TanStack Table**：仅在使用 `MDataTable` 时需要安装 `@tanstack/vue-table`。
