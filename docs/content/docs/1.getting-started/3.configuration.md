## 概览

模块级选项写在 `nuxt.config.ts` 的 `movk` 键下，在构建期生效。全部选项都有默认值，不写也能直接使用：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@movk/nuxt'],
  movk: {
    prefix: 'M',
    theme: { enabled: true },
    icon: { clientBundle: true },
    api: { enabled: true },
    zod: false
  }
})
```

运行时可调整的主题值放在 `app.config.ts`，见 [运行时配置](#运行时配置)。

## `prefix`

- **类型**：`string`
- **默认值**：`'M'`

组件名前缀。修改后组件名随之变化，例如 `prefix: 'My'` 时为 `MyAutoForm`、`MyDataTable`。composables 不受影响。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  movk: {
    prefix: 'My'
  }
})
```

## `theme`

主题模块的构建期配置。各字段的作用与效果见 [主题](/docs/getting-started/theme)。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  movk: {
    theme: {
      font: 'Alibaba PuHuiTi',
      radius: 0.375
    }
  }
})
```

::field-group
  ::field{name="enabled" type="boolean"}
  是否启用主题模块。默认 `true`。关闭后不再注入 `app.config.movk` 默认值、主题插件与 `MThemePicker` 组件。
  ::

  ::field{name="prefix" type="string"}
  Tailwind CSS 工具类前缀，用于生成模块组件的主题类。缺省时沿用 Nuxt UI 的 `ui.tailwindPrefix`。
  ::

  ::field{name="font" type="string | { name: string, href?: string }"}
  全局字体。内置字体（`'Alibaba PuHuiTi'`、`'OPPO Sans'`）只需写名字；自托管字体用对象形式补上样式表地址。缺省时不注入 `--font-sans`。
  ::

  ::field{name="radius" type="number"}
  默认圆角，单位 rem。缺省时不注入 `--ui-radius`，沿用 Nuxt UI 默认值或项目 CSS。
  ::

  ::field{name="radiuses" type="number[]"}
  `MThemePicker` 的圆角可选项，单位 rem。默认 `[0, 0.125, 0.25, 0.375, 0.5]`。
  ::

  ::field{name="neutralColors" type="string[]"}
  `MThemePicker` 的 neutral 色板可选项。默认 `['slate', 'gray', 'zinc', 'neutral', 'stone', 'taupe', 'mauve', 'mist', 'olive']`。
  ::
::

::note
颜色不在模块选项中配置，改用项目 CSS 中的 `@plugin "@nuxt/ui/colors"`；组件默认变体改用 `app.config.ts` 的 `ui.<组件>.defaultVariants`。见 [主题 · 颜色](/docs/getting-started/theme#颜色)。
::

## `icon`

::field-group
  ::field{name="clientBundle" type="boolean"}
  是否把模块组件与内置图标集（Lucide、Phosphor、Tabler）用到的图标注入 `@nuxt/icon` 的构建期图标包。默认 `true`。关闭后这些图标改为运行时按需请求。
  ::
::

图标数据来自项目安装的 `@iconify-json/*` 包，未安装的图标集会被跳过，不会导致构建失败。见 [主题 · 图标集](/docs/getting-started/theme#图标集)。

## `api`

API 域的配置：端点、认证、响应解析与 Toast。仅 Nuxt 模式可用。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  movk: {
    api: {
      endpoints: {
        default: { baseURL: '/api' },
        admin: { baseURL: '/admin-api' }
      },
      auth: { enabled: true }
    }
  }
})
```

::field-group
  ::field{name="enabled" type="boolean"}
  是否启用 API 域（`$api` 插件与 `useApiFetch` 系列）。默认 `true`。
  ::

  ::field{name="defaultEndpoint" type="string"}
  默认端点名。默认 `'default'`。
  ::

  ::field{name="debug" type="boolean"}
  是否在控制台输出请求日志。默认 `false`。
  ::

  ::field{name="endpoints" type="Record<string, ApiEndpointConfig>"}
  端点表。未声明时内置 `default: { baseURL: '/api' }`。
  ::

  ::field{name="auth" type="ApiAuthConfig"}
  认证注入与 401 处理。
  ::

  ::field{name="response" type="ApiResponseConfig"}
  业务状态码、数据解包与消息字段。
  ::

  ::field{name="toast" type="ApiToastConfig"}
  成功与失败提示。
  ::
::

::note{to="/docs/api/api-plugin"}
各字段的完整说明、合并优先级与安全建议见 API · 插件与端点配置。
::

::warning
仅当 `api.auth.enabled` 为 `true` 且 `tokenSource` 为 `'session'`（默认）时，模块才会登记 `nuxt-auth-utils`，此时生产环境须设置至少 32 个字符的 `NUXT_SESSION_PASSWORD`。
::

## `zod`

- **类型**：`MovkZodOptions | false`
- **默认值**：`false`

本地化 Zod 的校验文案，并为必填字段生成带字段名的提示。`z.config` 是全局单例，开启后应用内所有 Zod 校验（包括服务端）都使用该配置。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  movk: {
    zod: {
      locale: 'auto',
      locales: ['zh-CN']
    }
  }
})
```

::field-group
  ::field{name="locale" type="'auto' | string" required}
  校验文案语言。固定为某个 locale code（如 `'zh-CN'`），或 `'auto'` 跟随 `<UApp :locale>`。`'auto'` 只在客户端生效，服务端使用 `fallback`。
  ::

  ::field{name="fallback" type="string"}
  无法映射到 Zod 语言时使用的语言。默认 `'en'`。
  ::

  ::field{name="locales" type="string[]"}
  `'auto'` 模式下打包的语言列表。缺省时只打包 `fallback`；固定 `locale` 时无需设置。
  ::

  ::field{name="localeMap" type="Record<string, string>"}
  覆盖 locale code 到 `zod/locales` 导出名的映射，例如 `{ 'zh-Hans': 'zhCN' }`。
  ::

  ::field{name="required" type="boolean | { inputs?: (undefined | null | '')[] }"}
  必填提示。`true` 时输入为 `undefined` 视为缺失；对象形式可自定义视为缺失的值；`false` 关闭。默认 `true`。
  ::

  ::field{name="label" type="boolean"}
  必填提示是否插入 Schema 元数据中的 `label` / `title`。默认 `true`。
  ::

  ::field{name="jitless" type="boolean"}
  关闭 Zod 的 JIT 编译，用于禁止 `new Function` 的严格 CSP 环境。默认 `false`。
  ::
::

开启 `zod` 后，如需更细的控制，可在插件中通过 `movk:zod:config` 钩子提供优先级最高的 `customError`：

```ts [app/plugins/zod.ts]
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('movk:zod:config', (config) => {
    config.customError = (issue) => {
      if (issue.code === 'too_small' && issue.origin === 'string') {
        return `至少输入 ${issue.minimum} 个字符`
      }
    }
  })
})
```

返回空值时继续使用必填规则与语言包文案。

## 运行时配置

`app.config.ts` 中有两处与模块相关的键：

- `ui.movk<组件>`：组件主题覆盖，如 `ui.movkDataTable`、`ui.movkTree`，格式与 Nuxt UI 组件主题一致，见 [主题 · 组件样式覆盖](/docs/getting-started/theme#组件样式覆盖)。
- `movk`：运行时主题默认值，由 `theme` 选项生成，可在此覆盖。

```ts [app.config.ts]
export default defineAppConfig({
  movk: {
    radius: 0.5,
    icons: 'lucide',
    blackAsPrimary: false,
    picker: {
      radiuses: [0, 0.25, 0.5],
      neutralColors: ['slate', 'zinc']
    }
  }
})
```

::field-group
  ::field{name="radius" type="number"}
  默认圆角，单位 rem。默认取 `theme.radius`。
  ::

  ::field{name="icons" type="'lucide' | 'phosphor' | 'tabler'"}
  默认图标集。默认 `'lucide'`。
  ::

  ::field{name="blackAsPrimary" type="boolean"}
  是否默认以黑色（深色模式为白色）作为主色。默认 `false`。
  ::

  ::field{name="picker" type="{ radiuses?: number[], neutralColors?: string[] }"}
  `MThemePicker` 的可选项。默认取 `theme.radiuses` 与 `theme.neutralColors`。
  ::

  ::field{name="dir" type="'ltr' | 'rtl'"}
  文字方向。默认 `'ltr'`，可传给 `<UApp :dir>`。
  ::
::

## 国际化

组件文案跟随 `<UApp :locale>`，内置 `en` 与 `zh-CN` 两套，其他语言回退到英文。需要改写个别文案时，用 `extendMovkLocale` 在 Nuxt UI 的 locale 上覆盖 `movk` 字段：

```vue [app/app.vue]
<script setup lang="ts">
import { zh_cn } from '@nuxt/ui/locale'

const locale = extendMovkLocale(zh_cn, {
  searchForm: { search: '查询' }
})
</script>

<template>
  <UApp :locale="locale">
    <NuxtPage />
  </UApp>
</template>
```

在自定义组件中读取同一套文案可使用 `useMovkLocale()`，其返回的 `t('searchForm.search')` 按当前语言取值。
