## 介绍

Movk Nuxt 在 [Nuxt UI](https://ui.nuxt.com) 主题之上提供统一的运行时主题管理：颜色、圆角、字体、图标集与深色模式集中由一处控制，并可在运行时交互式调整、一键导出 CSS 变量或配置代码。

主题能力由三部分组成：

- **[模块默认值](/docs/getting-started/configuration)** ： 在 `nuxt.config.ts` 的 `movk.theme` 中声明可选项。
- **`ThemePicker` 组件** ： 面向用户的可视化调参面板，支持导出。
- **`useTheme` composable** ： 在脚本中读写主题状态、导出 CSS/配置。

## 启用与关闭

主题模块默认启用。关闭后不再注入 `appConfig` 默认值、theme 插件与 `ThemePicker` 组件：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  movk: {
    theme: { enabled: false }
  }
})
```

## ThemePicker 组件

`ThemePicker` 提供颜色、圆角、字体、图标集、深色模式的可视化切换，并能导出当前主题。

::tip{icon="i-lucide-box" to="/docs/components/theme-picker"}
查看 ThemePicker 的完整 props、事件与用法。
::

## useTheme

`useTheme` 暴露主题的响应式状态与导出方法，适合自定义主题面板或在业务逻辑中读取主题：

```ts
const {
  color, neutral, radius, font, icon, mode,
  exportCSS, exportConfig, resetTheme
} = useTheme()

// 读取/切换主题
color.value = 'green'
mode.value = 'dark'

// 导出当前主题
const css = exportCSS()
const config = exportConfig()
```

::tip{icon="i-lucide-square-function" to="/docs/composables/use-theme"}
查看 useTheme 返回的全部状态与方法。
::

## 字体

字体有两条独立的控制途径，优先级从高到低：

1. 用户在 `ThemePicker` 中的选择（存于 localStorage）
2. `movk.theme.font` ： 项目声明的默认字体
3. 项目 CSS 的 `@theme` ： 以上两项都没有时生效

前两项通过运行时注入的 `<style id="nuxt-ui-font">` 生效。该 style 没有层级（unlayered），按 CSS 级联规则会压过 `@theme` 产出的 `@layer theme`，因此**只要配置了 `movk.theme.font`，项目 CSS 里的 `--font-sans` 就不会生效**。

只用项目 CSS 控制字体时，不要配置 `movk.theme.font`：

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

@theme {
  --font-sans: "OPPO Sans 4.0", sans-serif;
}
```

需要支持运行时切换时，改为在配置中声明，并确保字体已登记在 `fonts` 中：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  movk: {
    theme: {
      font: 'OPPO Sans 4.0',
      fonts: [
        { name: 'OPPO Sans 4.0', href: '/fonts/oppo-sans/result.css' }
      ]
    }
  }
})
```

::warning
`fonts` 中缺省 `href` 的项会被视为托管在 Google Fonts。若部署环境无法访问 Google，请为每一项显式提供 `href`。未登记在 `fonts` 中的字体不会产生任何请求。
::

## 圆角

`--ui-radius` 遵循与字体相同的三级优先级：`ThemePicker` 选择 > `movk.theme.radius` > 项目 CSS。缺省时模块不注入该变量，沿用 `@nuxt/ui` 的默认值（`0.25rem`），项目可在自己的 CSS 中覆盖：

```css [app/assets/css/main.css]
@theme {
  --ui-radius: 0.5rem;
}
```

## 从 1.x 升级

字体与圆角的存储语义已变更：旧版本把「含默认值的生效值」写入 `localStorage`，新版本只存「用户的显式选择」。若沿用同一个键，升级前写入的默认值会被当作用户选择，压过 `theme.font` 与 `theme.radius`。

因此这两项的存储键带上了 `-v2` 后缀，升级前的数据不再被读取，并会在客户端首次加载时清理。**用户此前通过 `ThemePicker` 选择的字体与圆角会被重置一次**，颜色、图标等其余选择不受影响。

## 可选项定制

颜色别名、圆角档位、字体列表、neutral 颜色均可在 `movk.theme` 中覆盖，作为 `ThemePicker` 与 `useTheme` 的取值范围：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  movk: {
    theme: {
      colors: ['primary', 'secondary', 'success', 'info', 'warning', 'error'],
      radiuses: [0, 0.125, 0.25, 0.375, 0.5],
      fonts: [
        { name: 'Alibaba PuHuiTi', href: 'https://cdn.mhaibaraai.cn/fonts/alibaba-puhuiti.css' }
      ]
    }
  }
})
```
::tip{icon="i-lucide-box" to="/docs/getting-started/configuration"}
各字段含义见模块配置 · Theme
::

## 导出与复用

`ThemePicker` 与 `useTheme.exportCSS()` 导出的 CSS 变量可直接写入项目的 `main.css`，将运行时调试结果固化为默认主题：

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@nuxt/ui";

:root {
  /* 粘贴 exportCSS() 导出的变量 */
}
```
