## 环境要求

- **Node.js**：`^20.19.0 || >=22.12.0`
- **Nuxt**：`>=4.4.2`
- **Nuxt UI**：v5
- **Tailwind CSS**：`^4.2.0`
- **Zod**：`>=4.3.6`

## 使用模板

[Movk Nuxt Starter](https://github.com/mhaibaraai/movk-nuxt-starter) 是已集成 `@movk/nuxt` 的 Nuxt 4 项目模板（[在线预览](https://movk-nuxt-starter.vercel.app)）：

```bash
npm create nuxt@latest -- -t gh:mhaibaraai/movk-nuxt-starter
```

::tip{to="https://github.com/new?template_name=movk-nuxt-starter&template_owner=mhaibaraai" target="_blank"}
也可以在 GitHub 上点击 **Use this template** 基于模板创建仓库。
::

## 添加到 Nuxt 项目

::steps{level="3"}

### 安装依赖

::code-group
```bash [pnpm]
pnpm add @movk/nuxt @nuxt/ui tailwindcss zod
```

```bash [npm]
npm install @movk/nuxt @nuxt/ui tailwindcss zod
```

```bash [yarn]
yarn add @movk/nuxt @nuxt/ui tailwindcss zod
```
::

使用 `MDataTable` 时另装 `@tanstack/vue-table`（可选 peer 依赖，不使用表格可以不装）：

::code-group
```bash [pnpm]
pnpm add @tanstack/vue-table
```

```bash [npm]
npm install @tanstack/vue-table
```

```bash [yarn]
yarn add @tanstack/vue-table
```
::

::note
当前 v2 预览版需要 Nuxt UI v5 预览构建。安装上述依赖后，将 `@nuxt/ui` 替换为以下固定提交的预览包（其他包管理器使用对应的安装命令）：

```bash
pnpm add https://pkg.pr.new/@nuxt/ui@76645ed
```
::

### 注册模块

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@movk/nuxt']
})
```

模块会自动登记 `@nuxt/ui`、`@vueuse/nuxt`、`@nuxt/image` 与 `nuxt-site-config`，无需重复添加到 `modules`。

### 引入样式

在项目 CSS 入口中先引入 Tailwind CSS，再引入 `@movk/nuxt`，并在 `nuxt.config.ts` 的 `css` 中注册该文件：

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@movk/nuxt";
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@movk/nuxt'],
  css: ['~/assets/css/main.css']
})
```

::note
`@movk/nuxt` 已包含 `@nuxt/ui` 的样式，无需再写 `@import "@nuxt/ui"`。整个项目只能有一个 `@import "tailwindcss"`，多出的 Tailwind 入口会覆盖模块注入的 `--font-sans` 等主题变量。漏引 `@movk/nuxt` 时，构建期会在终端给出警告。
::

### 配置颜色

颜色沿用 Nuxt UI v5 的配置方式，在同一个 CSS 文件中通过 `@nuxt/ui/colors` 插件声明。模块不注入默认色，未声明时使用 Nuxt UI 的默认值：

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@movk/nuxt";

@plugin "@nuxt/ui/colors" {
  primary: blue;
  neutral: slate;
}
```

::tip{to="/docs/getting-started/theme"}
组件样式覆盖、运行时切换颜色与圆角见主题。
::

### 用 `<UApp>` 包裹应用

`<UApp>` 为 Toast、Tooltip 与命令式弹窗提供全局上下文，`useMessageBox` 与 API 的 Toast 提示都依赖它：

```vue [app/app.vue]
<template>
  <UApp>
    <NuxtPage />
  </UApp>
</template>
```

### 安装图标集

组件图标来自 Iconify 的 `lucide` 图标集。安装对应的 `@iconify-json` 包后，模块会在构建期把组件用到的图标打进产物；未安装时改为运行时向 Iconify API 请求，内网或离线环境会拿不到图标。

::code-group
```bash [pnpm]
pnpm add -D @iconify-json/lucide
```

```bash [npm]
npm install -D @iconify-json/lucide
```

```bash [yarn]
yarn add -D @iconify-json/lucide
```
::

模块只负责自身组件的图标。项目代码里的图标名需开启 `@nuxt/icon` 的扫描才会一并打包：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  icon: {
    clientBundle: {
      scan: { globInclude: ['**/*.{vue,jsx,tsx,ts,md,mdc,mdx,yml,yaml}'] }
    }
  }
})
```

::note
`@nuxt/icon` 默认的 `globInclude` 不含 `.ts`，写在 composable 或常量文件中的图标名会漏扫，因此这里显式加上 `ts`。
::

::

## 第一个表单

安装完成后，组件与 composables 均自动导入：

```vue [app/pages/index.vue]
<script setup lang="ts">
import type { z } from 'zod'

const { afz } = useAutoForm()

const schema = afz.object({
  username: afz.string().min(3).meta({ label: '用户名' }),
  email: afz.email().meta({ label: '邮箱' })
})

const state = ref<Partial<z.output<typeof schema>>>({})
</script>

<template>
  <MAutoForm v-model="state" :schema="schema" />
</template>
```

::note
Movk Nuxt 使用 Zod v4，字符串格式请用顶层校验函数（`z.email()`、`z.url()`、`z.iso.datetime()`），而非 v3 的 `z.string().email()`。
::
