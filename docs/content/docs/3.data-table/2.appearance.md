## 斑马纹与边框

`stripe` 控制偶数行底色；`bordered` 支持布尔与对象形态，对象形态通过 `color`/`width`/`style` 自定义纵向边框：

::component-example
---
name: DataTableAppearanceExample
options:
  - name: stripe
    label: stripe
    items: [true, false]
    default: true
  - name: bordered
    label: bordered
    items:
      - true
      - false
      - { color: 'var(--ui-primary)', width: '2px', style: 'dashed' }
    default: true
  - name: density
    label: density
    items: ['compact', 'normal', 'comfortable']
    default: normal
  - name: fit-content
    label: fitContent
    items: [true, false]
    default: false
  - name: sticky
    label: sticky
    items: [true, false]
    default: true
---
::

## `emptyCell` 空值占位

`emptyCell` 支持字符串、函数模板（返回 VNode）与 `false`，分别用于自定义文本、自定义节点与完全关闭。列级 `emptyCell` 优先于全局：

::component-example
---
name: DataTableEmptyCellVariantsExample
options:
  - name: empty-cell
    label: emptyCell
    items:
      - '—'
      - 'N/A'
      - '暂无'
      - false
    default: '—'
---
::
