## What is Movk Nuxt

Movk Nuxt is a **schema-driven admin CRUD toolkit** built on [Nuxt UI](https://ui.nuxt.com). It coordinates the work that repeats across admin pages:

- Describe data with [Zod v4](https://zod.dev) schemas, generate forms with `MAutoForm` and search criteria with `MSearchForm`.
- Configure `MDataTable` columns declaratively, including selection, sorting, hierarchical data and pagination.
- In Nuxt, use `useApiFetch` to manage endpoints, authentication, business status codes and notifications, connecting data to forms and tables.

Use it for admin dashboards, internal tools and operations systems with many CRUD pages. For general UI components alone, use Nuxt UI directly.

## Capability domains

::card-group
  :::card{icon="i-lucide-square-pen" title="Forms" to="/en/docs/auto-form"}
  `MAutoForm` generates fields, validation and layouts from Zod schemas, with custom controls, conditional visibility and arrays of objects. `MSearchForm` uses the same schema infrastructure for collapsible search bars.
  :::

  :::card{icon="i-lucide-table" title="Data tables" to="/en/docs/data-table"}
  `MDataTable` builds on TanStack Table, with data columns and selection, index, expansion and action columns, plus sorting, pinned columns, hierarchical data and pagination.
  :::

  :::card{icon="i-lucide-cloud" title="API (Nuxt only)" to="/en/docs/api"}
  The `useApiFetch` family extends `useFetch` with multiple endpoints, authentication injection, business status validation, response unwrapping and Toast notifications, plus upload/download progress and streaming requests.
  :::

  :::card{icon="i-lucide-box" title="Components" to="/en/docs/components/date-picker"}
  `MDatePicker`, `MTree` and `MMessageBox` cover common admin interactions. `MThemePicker` and `useTheme` manage runtime themes.
  :::
::

## Two integration modes

| | Nuxt mode | Vue + Vite mode |
| --- | --- | --- |
| Integration | Nuxt module `@movk/nuxt` | Vite plugin `@movk/nuxt/vite` + Vue plugin `@movk/nuxt/vue-plugin` |
| Forms, search and tables | Available | Available |
| DatePicker, Tree, MessageBox and ThemePicker | Available | Available |
| `useAutoForm`, `useTheme`, `useDateFormatter`, `useMessageBox`, `useMovkLocale` | Available | Available |
| API domain (`useApiFetch` family, `$api`, upload/download, streaming, authentication and Toast integration) | Available | Unavailable |

The API domain depends on Nuxt's server runtime and `runtimeConfig`, so it is available only in Nuxt mode. Choose your own request solution for Vue + Vite projects.

::note{to="/en/docs/getting-started/vue"}
See Vue / Vite integration for plain Vue + Vite projects.
::

## Dependencies

- **Nuxt UI v5**: components use Nuxt UI's themes, colors and localization mechanisms.
- **Tailwind CSS v4**: styles compile through the project's single Tailwind entry point.
- **Zod v4**: the source of form and search schemas.
- **TanStack Table**: install `@tanstack/vue-table` only when using `MDataTable`.
