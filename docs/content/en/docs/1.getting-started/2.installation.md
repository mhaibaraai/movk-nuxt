## Requirements

- **Node.js**: `^20.19.0 || >=22.12.0`
- **Nuxt**: `>=4.4.2`
- **Nuxt UI**: v5
- **Tailwind CSS**: `^4.2.0`
- **Zod**: `>=4.3.6`

## Start from a template

[Movk Nuxt Starter](https://github.com/mhaibaraai/movk-nuxt-starter) is a Nuxt 4 template with `@movk/nuxt` already integrated ([live preview](https://movk-nuxt-starter.vercel.app)):

```bash
npm create nuxt@latest -- -t gh:mhaibaraai/movk-nuxt-starter
```

::tip{to="https://github.com/new?template_name=movk-nuxt-starter&template_owner=mhaibaraai" target="_blank"}
You can also click **Use this template** on GitHub to create a repository.
::

## Add to a Nuxt project

::steps{level="3"}

### Install dependencies

::code-group
```bash [pnpm]
pnpm add @movk/nuxt @nuxt/ui tailwindcss zod
```

```bash [npm]
npm install @movk/nuxt @nuxt/ui tailwindcss zod
```

```bash [yarn]
yarn add @movk/nuxt @nuxt/ui tailwindcss zod
```
::

Install `@tanstack/vue-table ^9.3.1` separately when using `MDataTable`. Version 8 is not supported. This is an optional peer dependency, so projects without tables can omit it:

::code-group
```bash [pnpm]
pnpm add @tanstack/vue-table@^9.3.1
```

```bash [npm]
npm install @tanstack/vue-table@^9.3.1
```

```bash [yarn]
yarn add @tanstack/vue-table@^9.3.1
```
::

::note
The current v2 preview requires the Nuxt UI v5 preview build. After installing the dependencies above, replace `@nuxt/ui` with the pinned preview URL below (use the equivalent install command for your package manager):

```bash
pnpm add https://pkg.pr.new/@nuxt/ui@19681d4
```
::

### Register the module

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@movk/nuxt']
})
```

The module registers `@nuxt/ui`, `@vueuse/nuxt`, `@nuxt/image` and `nuxt-site-config` automatically. You do not need to add them to `modules` again.

### Import styles

Import Tailwind CSS first and `@movk/nuxt` second in the project's CSS entry point, then register that file in `nuxt.config.ts`:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@movk/nuxt";
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['@movk/nuxt'],
  css: ['~/assets/css/main.css']
})
```

::note
`@movk/nuxt` includes Nuxt UI's styles, so a separate `@import "@nuxt/ui"` is unnecessary. Keep exactly one `@import "tailwindcss"` in the project: additional entry points can overwrite injected theme variables such as `--font-sans`. A missing `@movk/nuxt` import produces a build-time terminal warning.
::

### Configure colors

Use Nuxt UI v5's `@nuxt/ui/colors` plugin in the same CSS file. Movk Nuxt does not inject color defaults; without this declaration, Nuxt UI's defaults apply:

```css [app/assets/css/main.css]
@import "tailwindcss";
@import "@movk/nuxt";

@plugin "@nuxt/ui/colors" {
  primary: blue;
  neutral: slate;
}
```

::tip{to="/en/docs/getting-started/theme"}
See Themes for component style overrides and runtime color and radius switching.
::

### Wrap the application in `<UApp>`

`<UApp>` provides the shared context for Toast, Tooltip and imperative dialogs. Both `useMessageBox` and the API domain's Toast notifications depend on it:

```vue [app/app.vue]
<template>
  <UApp>
    <NuxtPage />
  </UApp>
</template>
```

### Install icon collections

Component icons come from Iconify's `lucide` collection. With the corresponding `@iconify-json` package installed, the module bundles the icons used by its components at build time. Otherwise icons are requested from the Iconify API at runtime, which may be unavailable on private networks or offline.

::code-group
```bash [pnpm]
pnpm add -D @iconify-json/lucide
```

```bash [npm]
npm install -D @iconify-json/lucide
```

```bash [yarn]
yarn add -D @iconify-json/lucide
```
::

The module handles its own component icons. Enable `@nuxt/icon` scanning to bundle icon names from your project code too:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  icon: {
    clientBundle: {
      scan: { globInclude: ['**/*.{vue,jsx,tsx,ts,md,mdc,mdx,yml,yaml}'] }
    }
  }
})
```

::note
The default `globInclude` in `@nuxt/icon` excludes `.ts`. Include it explicitly to scan icons declared in composables or constants.
::

## Your first form

Components and composables are auto-imported after installation:

```vue [app/pages/index.vue]
<script setup lang="ts">
import type { z } from 'zod'

const { afz } = useAutoForm()

const schema = afz.object({
  username: afz.string().min(3).meta({ label: 'Username' }),
  email: afz.email().meta({ label: 'Email' })
})

const state = ref<Partial<z.output<typeof schema>>>({})
</script>

<template>
  <MAutoForm v-model="state" :schema="schema" />
</template>
```

::note
Movk Nuxt uses Zod v4. Use top-level string format validators such as `z.email()`, `z.url()` and `z.iso.datetime()`, rather than v3's `z.string().email()`.
::
